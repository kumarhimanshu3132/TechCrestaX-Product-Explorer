# Product Explorer - TechCrestaX Assessment

**Live Demo:** [Vercel Deployment Link Yahan Daal Dena Deploy Hone Ke Baad]

## Features Implemented

- Responsive Product Grid with 20 items displaying image, name, price, and category.
- Indian currency formatting (INR) using `Intl.NumberFormat`.
- Real-time search filtering by product name.
- Category filtering via dropdown menu.
- Price sorting (Low to High).
- Handled empty state ("No products match your search or filters").

## Technology Stack

- React 18
- TypeScript
- Pure CSS
- Vite

## Local Setup Instructions

1. Clone the repository:
   `git clone `
2. Navigate to the project directory:
   `cd product-explorer`
3. Install the dependencies:
   `npm install`
4. Start the development server:
   `npm run dev`
